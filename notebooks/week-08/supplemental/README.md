## `dense-nn-m4.ipynb`

A dense network identifying members of the globular cluster M4 from Gaia astrometry.

**This is the same task HW6 sets you.** It is here on purpose: the worked example in class
is MNIST, and the homework asks you to carry that method to new data yourself. Read this
one if you get stuck — particularly for how the catalogue is loaded and the labels are
built — but the thinking HW6 is asking for is the part that is not in here.
