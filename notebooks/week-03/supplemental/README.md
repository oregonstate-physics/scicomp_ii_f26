# Week 3 — supplemental

Not taught, not graded, and not required. The weekly completion check ignores this
folder; read it if the week interested you.

## `boltzmann-ising-metropolis.ipynb`

The Boltzmann distribution and a 2-D Ising model, motivating Markov chains and the
Metropolis algorithm before applying them to inference.

It sits here rather than in the week because Metropolis is already taught in
`01-intro-to-sampling`, so this is a second implementation of the same algorithm: it adds
statistical-mechanics motivation and a 2-D lattice, but no new method. It is also a
*simulation* rather than measured data, which is the other reason it is optional.
