## `venus-volcanoes.ipynb`

A convolutional network finding volcanoes in Magellan radar images of Venus — the surface
is permanently under cloud, so radar is the only way to see it.

A second application of the CNNs taught in `03-intro-to-cnns`. The image chips are
committed to `data/venus/`, so it runs as it stands, with nothing to download.
